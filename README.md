# 부천 집 비교

지금 집과 갈아타기 후보 4곳을 부천 아파트 중에서 조건으로 골라 비교하는 앱입니다.

- **지도**: 카카오맵 (자두·정비맵과 같은 키). 부천 밖으로는 움직이지 않고, 부천 밖은 흐리게 보입니다.
- **단지 고르기**: 넣을 칸(지금 집·후보 1~4)을 고르고, 동·가격(기본 6~9억)·면적·준공·거래 건수로 거르면 조건에 맞는 단지가 목록과 지도 위 가격 칩으로 떠요(네이버페이부동산 지도처럼). 누르면 그 칸에 들어갑니다. '지도 화면 안만'을 켜면 지금 보이는 지도 안 단지만 남습니다.
- **정비구역**: 부천 정비구역 24곳 경계와 진행 단계 (정비맵 자료).
- **비교**: 단지 개요, 최근 5년 시세, 최근 실거래·매물, 초·중학교, 갈아타기 자금 계산.

## 자료
- `data/bucheon.json`: 부천 아파트 단지별 실거래 요약 — 분양시장 레이더(New-Build_Rader)의 국토부 실거래 캐시로 **매일 08:17(한국시간) 자동 갱신** (`.github/workflows/deploy.yml`, `scripts/build_data.py`).
- `data/zones.json`: 부천 정비구역 (국토교통부 정비구역 2026.10 · 경기도 정비사업 추진현황 2025.10, 정비맵에서 가져옴)
- `data/bounds.json`: 부천 구·동 경계 (통계청 2013, southkorea-maps)
- 송내역파인푸르지오1단지·신성미소지움·팰리스카운티·경남아너스빌 4곳은 2026년 11월 중순 조사한 시세·매물·학교가 `app.js`의 `PROFILE_LIST`에 있어 고르면 그 정보가 쓰이고, 그 밖의 단지는 실거래 자료로 자동으로 채워집니다.
