# 부천 집 비교

우리 집을 등록하고 갈아타기 후보 4곳을 부천 아파트 중에서 조건으로 골라 비교하는 앱입니다. 누구나 자기 집을 등록해 쓸 수 있고, 등록 내용은 각자의 기기(브라우저)에만 저장됩니다.

- **우리 집 등록**: 부천 아파트 목록에서 찾거나, 목록에 없으면(빌라·오피스텔 등) 이름·시세·면적을 직접 입력하고 주소 검색이나 지도 클릭으로 위치를 정합니다.

- **지도**: 카카오맵 (자두·정비맵과 같은 키). 부천 밖으로는 움직이지 않고, 부천 밖은 흐리게 보입니다.
- **단지 고르기**: 넣을 칸(우리 집·후보 1~4)을 고르고, 동·가격(기본 6~9억)·면적·준공·거래 건수로 거르면 조건에 맞는 단지가 목록과 지도 위 가격 칩으로 떠요(네이버페이부동산 지도처럼). 누르면 그 칸에 들어갑니다. '지도 화면 안만'을 켜면 지금 보이는 지도 안 단지만 남습니다.
- **생활편의**: 대형마트·다이소·시장 위치를 지도에 표시하고, 비교표에 단지별로 가장 가까운 곳과 거리를 보여줍니다 (카카오 장소 검색, 기기에 7일 저장).
- **면적·타입**: 단지별 타입(전용·공급면적, 평형, 방·욕실, 타입별 12개월 평균·최근 거래가)과 네이버부동산 평면도 링크. 공급면적·방·욕실을 확인하지 못한 타입은 전용면적으로 추정해 '추정'으로 표시합니다.
- **세대수·역세권 필터**: 세대수(300·500·1,000세대 이상), 지하철역 도보 시간(5·10·15분 이내, 15분 초과)으로 거릅니다.
- **비교**: 단지 개요, 최근 5년 시세, 최근 실거래·매물, 초·중학교, 갈아타기 자금 계산.

## 자료
- `data/bucheon.json`: 부천 아파트 단지별 실거래 요약 — 분양시장 레이더(New-Build_Rader)의 국토부 실거래 캐시로 **매일 08:17(한국시간) 자동 갱신** (`.github/workflows/deploy.yml`, `scripts/build_data.py`).
- `data/types.json`: 국토부 아파트 매매 실거래 원자료로 만든 단지·전용면적(타입)별 거래 — 인증키가 있을 때 매일 받음 (`scripts/fetch_trades.py`). 없으면 레이더 캐시의 일부 거래로 대신합니다.
- `data/kapt.json`: 국토부 공동주택관리정보시스템(K-apt) 단지 정보 — 세대수·동수·시공사·주차·지하철역/버스 도보 시간. 인증키가 있을 때 매일 받음 (`scripts/fetch_kapt.py`)
- `data/bounds.json`: 부천 구·동 경계 (통계청 2013, southkorea-maps)
- 송내역파인푸르지오1단지·신성미소지움·팰리스카운티·경남아너스빌 4곳은 2026년 11월 중순 조사한 시세·매물·학교가 `app.js`의 `PROFILE_LIST`에 있어 고르면 그 정보가 쓰이고, 그 밖의 단지는 실거래 자료로 자동으로 채워집니다.

## 처음 켜기
Settings → Pages → Source를 **GitHub Actions**로 바꾸면 첫 배포가 시작됩니다.

## 세대수·역 도보 시간·타입별 시세 켜기 (한 번만)
1. 공공데이터포털(data.go.kr)에서 **국토교통부_공동주택 단지 목록제공 서비스**, **국토교통부_공동주택 기본 정보제공 서비스**를 활용신청합니다. 타입별 실거래는 **국토교통부_아파트 매매 실거래가 자료**(레이더에서 이미 쓰는 것)를 씁니다 (분양시장 레이더에 쓰는 인증키 그대로 사용, 보통 바로 승인).
2. 이 저장소 Settings → Secrets and variables → Actions → **New repository secret**: 이름 `DATA_GO_KR_KEY`, 값에 인증키(일반 인증키 Decoding).
3. Actions → 자료 만들기 및 배포 → Run workflow.

키를 넣기 전에는 세대수 필터가 동작하지 않고, 역 도보 시간은 지도 위치로 가장 가까운 역까지 거리를 재서 추정합니다(직선거리×1.3, 분당 70m).
